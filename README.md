# Shijun Studio

個人・少人数で制作する2Dゲーム向けに、UIの1画面、イラスト・素材、小さな機能や場面の制作をお手伝いします。

## ご依頼いただけること

- 特定のゲームに合わせたUI 1画面の制作
- 用途を決めた2Dイラスト・素材の制作
- 既存の2Dプロジェクト内の小さな1機能・1場面の実装

必要に応じて、担当工程の仕様確認やレビューも行います。未決事項・修正点を整理し、成果物とあわせて次の担当者に共有します。企画全体の最終決定者は依頼側です。

## ご相談から納品まで

1. ゲームの概要、必要な成果物、使用エンジン、希望時期、予算の目安を伺います。
2. 担当範囲、納品形式、修正回数、報酬、支払時期を文面で確認します。
3. 合意後に制作し、決めた確認地点でレビューを受けます。
4. 成果物と、担当した工程の確認事項をお渡しします。

費用は仕様と作業量を確認してから個別に見積もります。ゲーム全体の完成請負は、この案内の対象に含めていません。
