# Shijun Studio

## ご依頼いただけること

- 特定のゲームに合わせたUI 1画面の制作
- 用途を決めた2Dイラスト・素材の制作
- 既存の2Dプロジェクト内の小さな1機能・1場面の実装

チーム制作では、担当工程の仕様確認、未決事項の整理、レビュー、次の担当者への受け渡しもご相談ください。企画全体の最終決定者は依頼側です。

## ご相談から納品まで

1. ゲームの概要、必要な成果物、使用エンジン、希望時期を伺います。
2. 担当範囲、納品形式、修正回数、報酬、支払時期を文面で確認します。
3. 合意後に制作し、決めた確認地点でレビューを受けます。
4. 成果物と、担当した工程の確認事項をお渡しします。

費用は仕様と作業量を確認してから個別に見積もります。ゲーム全体の完成請負は、この案内の対象に含めていません。
