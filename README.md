# Shijun Studio

静的LPと既存サイトの修正を、AIを使って短納期で制作します。個人事業のため、ご依頼は1件ずつ対応します。

*Static LP and site fixes, shipped fast with AI.*

## 対応範囲

- 静的LPの制作（1ページ完結）
- 既存サイトの修正・レスポンシブ対応
- 表示崩れ・レイアウトの調整

サーバー構築・CMS構築・運用保守は対応していません。

## 進め方

1. 要件確認（参考URL・カンプ・修正箇所）
2. お見積り
3. 制作
4. 表示確認（PC・タブレット・スマートフォン）
5. 修正2回まで
6. 納品（HTML / CSS / 画像のzip）

## 使用技術

- HTML / CSS / JavaScript
- 画像は商用利用可能なフリー素材を使用

制作には生成AIを活用しています。生成物は必ず自分で確認し、表示と動作の検証を行った上で納品します。
